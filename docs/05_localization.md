# 05 相对定位与时间同步

> RQ4：仅有距离（UWB）与邻居广播状态时，如何得到可靠的相对位置？模块数增加、遮挡、时钟偏移怎么办？

## 5.1 问题定义

相对定位的输入通常有三类：**测距**（UWB 的 ToF/TWR/TDOA）、**邻居共享状态**（速度、高度、航向、时间戳）、**自身惯性**（IMU）。输出是模块间相对位置/速度。难点：

- 只有距离没有方位时，可观测性依赖运动与几何；
- UWB 非视距/多径产生重尾噪声与离群值；
- 模块数增加使全连接测距的时隙需求平方增长；
- 无硬件时间同步时，时钟偏移直接变成距离/预测误差。

## 5.2 方法族与代表工作

- **体制与全景**：UWB 多机定位综述 [22] 覆盖自组网/动态部署、协同定位、协同感知与数据集，是选型入口（TWR vs TDOA、有无基础设施）。
- **距离 + 运动模型融合**：CRL [23] 把每对主机-邻居的相对运动动力学并入统一模型，把邻居间距离作为额外信息，用微分几何做可观测性分析，证明可观测子空间扩大；用 LV 核 EKF 抗重尾噪声。
- **规模化**：GNSS-denied 集群 [24] 用谱聚类分簇，簇内矩阵补全 + MDS，簇间锚点融合；案例用 OTFS 同时通信与测距。
- **时间同步**：联合估计 [25] 把时间偏移与相对位姿放在一个优化问题里，用 SDR 得到无损松弛，再由粗到细迭代。
- **嵌入式实现**：轻量集群 [26] 在 33 g、168 MHz MCU 上融合 UWB 与邻居状态，13 机 16 Hz 下作者报告位置误差 < 0.2 m；并提出"状态漂移会使系统重新可观测"的反直觉结论。

## 5.4 证据强度与局限

- 仅 [22] 为 A/C 级综述；其余为 B 级预印本，实验平台与你的系统（单旋翼、倾转、绑缚）不同。
- 可观测性分析 [23] 假设运动模型已知且平滑；单旋翼模块姿态变化更剧烈，模型需替换。
- 没有工作同时处理"UWB 遮挡 + ESP-NOW 广播 + 时钟偏移 + 模块数变化"；这是 10 章 G3、G4。

## 5.5 对目标系统的启示（推断）

1. **观测融合**：UWB 距离 + ESP-NOW 邻居状态（带时间戳）+ IMU，做成相对位置 EKF；用鲁棒核处理 UWB 离群值（对齐 [23][26]）。
2. **时间同步**：先用消息时间戳估计偏移/漂移（对齐 [25]），再做预测；同步精度决定融合权重。
3. **扩展路径**：模块数少时全连接 TWR；增加后按 [24] 分簇，或改用调度式测距。
4. **风险**：货物遮挡会同时恶化 UWB 与无线链路；需要视距检测与降级策略。

**本章结论**：距离 + 邻居状态 + IMU 的融合是成熟路线，嵌入式可落地；空白在于"无时间同步 + 广播链路 + 单旋翼姿态"三者叠加的实现与误差分析。
