# 23 相关工作对照表（主稿 Table 1）

> **本章定位**：22 章 22.4 的 Table 1 需要一张"与谁比、差异在哪"的表。02–09 章已经按方法族
> 做过横向对比，但那些表是**按章分的**；审稿人看的是**按主张分的**——每一行都要回答
> "这篇工作和你的 claim 差在哪"。本章把 78 篇核心工作中与本文 claim 最近的 43 篇抽出来，
> 统一成六列。
>
> 列定义：
> - **平台与耦合**：模块形态 + 机械连接方式（刚性绑缚/对接/缆绳/弹性）；
> - **通信假设**：显式通信结构，或"未讨论"——很多工作根本不报链路预算，这正是本文的切入点；
> - **力感知/检测**：有无力测量、有无残差检测；
> - **故障/重构**：故障假设是"已知"还是"要检测"；
> - **与本文差异**：只写差异，不写优劣。

## 23.2 三条增量（审稿人最关心的"你和他们差在哪"）

**增量 1：单旋翼倾转 + 刚性绑缚 + 货物**
现有模块化工作 [2][4][5][6][7][80][81] 的模块几乎都是四旋翼，可行力旋量集合近似常值；
单旋翼模块 [10][11][12] 已被证明可协同搬货，但通信不受限、无测力。本文的交叉点是
"单旋翼模块 + 刚绑货物 + 12 路测力 + 250 kbps 链路"，四条同时成立的工作在 78 篇里没有。

**增量 2：故障检测按物理时间算，而不是按通信节拍**
[5][6][7][35] 都假设故障已识别，检测被简化；[85][86] 做的是单机外力认证/估计。
本文把"检测预算"拆成样本域与物理时间（15、19 章），指出 20 Hz 检测 P95 超 150 ms 预算，
并给出 26.7 Hz / 原始 80 SPS 的可行点。这是方法层差异，不是平台差异。

**增量 3：证明"内力可测 ≠ 内力可分离"，并据此收缩 claim**
[9] 的抓取矩阵显式区分内外力，但那是控制分配层面的代数分解；[10]–[12] 用控制器隐含处理，
[14][15] 靠缆绳张力。本文用 20 章说明：12 路测点里 69% 落在零空间，装夹预紧与热漂移
比故障信号大 1–2 个数量级——因此主张收缩为"相对基线的力残差检测"，而不是"内力控制"。
这条**负面结论**反而是最容易被审稿人接受的贡献：它给出了可复现的工程上界。
