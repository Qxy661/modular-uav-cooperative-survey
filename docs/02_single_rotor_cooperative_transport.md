# 02 单旋翼模块与协同搬运

> 本章回答：多个单旋翼模块刚性绑缚搬运货物时，控制怎么分、力怎么分、通信能不能省。这一章与你的系统最接近，优先级最高。

## 两条技术路线

- **刚性连接**：模块与货物刚性固定，整机近似一个刚体，控制问题变成"合力/合力矩分配 + 各部分内力"。代表：Oishi 系列、Michael 等、H-ModQuad 类。
- **柔性连接**：缆绳、弹性杆、可变刚度连接，需要处理松弛-张紧、摆动、耦合。代表：缆绳悬挂协同运输、桌面力学、CrazyMARL、GPAC。

你的"绑缚货物"更接近刚性连接，但绑缚点有测力计，意味着可以测得内力——这正是刚性连接路线里最有价值的信息。

## 2.1 Scratch Team：单旋翼机器人团队与去中心化协同运输（2023）

**链接**：https://arxiv.org/abs/2307.00705

**做了什么**：用多个单旋翼机器人协同搬运货物，提出去中心化控制器，对质量与质心波动、机器人失效具有鲁棒性，并具有对动力学误差的渐近稳定性；控制器由两部分并联组成——把系统变成严格正实（SPR）的反馈控制器，以及让货物渐近到达目标的非线性控制器。作者报告仿真用 8 台和 10 台机器人搬运两种形状，实验用三种规格的机器人搬运约 3 kg、最大长度 1.6 m 的矩形货物，并在机器人失效与质心波动下继续飞行。

**重点分析**：这是与你系统最接近的一篇：单旋翼、刚性连接、去中心化、未知货物、可失效。它的关键思想是**用反馈把"未知的被控对象"变成严格正实系统**，再把稳定性归到 SPR 理论上。对工程实现，这意味着控制器不依赖精确的货物模型，但需要知道连接位置或至少其近似。你们有测力计，可以把"力"作为额外反馈，进一步降低对模型和通信的依赖。

**可参考点**：
- 控制器结构（SPR 化反馈 + 非线性跟踪）可直接作为基线。
- 异构模块（不同规格/老化程度）也能协同，符合你们"模块不一定要同款"的演进方向。
- 实验规模与货物尺寸可作为你们的对照基准。

## 2.2 多个单旋翼机器人与未知负载的去中心化控制（2022，ICRA）

**链接**：https://arxiv.org/abs/2111.01963

**做了什么**：用刚性连接的单旋翼机器人搬运未知负载，提出对未知严格正实系统保证误差动力学渐近稳定的去中心化控制器；反馈控制器在考虑共享连接位置的情况下把不稳定系统变成 SPR。仿真验证不同形状、尺寸大于载体的未知负载；实验用 8 台机器人搬运约 2.7 kg、最大长度 1.6 m 的未知负载，并在机器人失效下继续；还演示了连接位置不共享（稳定性不严格保证）时仍能搬运。

**重点分析**：比上一篇更明确地处理"未知负载"与"连接位置是否共享"两个现实问题。**连接位置不共享**这一点很重要：ESP-NOW 广播带宽有限时，你们很可能无法高频同步每个绑缚点的几何关系；论文表明即使不严格满足稳定性条件，系统仍可能工作——但这只是实验现象，不是保证。

**可参考点**：
- 把"连接位置"分为必共享（低频、静态）与可估计（高频、动态）两类。
- 失效下的实验流程可作为你们容错实验的模板。

## 2.3 可变连接机构与自主协同运输（2021，IROS）

**链接**：https://arxiv.org/abs/2109.10575

**做了什么**：提出覆盖"起飞前设置到受控飞行"全流程的协同运输系统（软件 + 硬件），根据货物特性改变机器人连接位置；用机器人两两之间的贝叶斯估计得到货物重心，再按可控性优先选择连接构型。仿真与实验（8 台机器人、约 3.2 kg、最大长度 1.76 m 的未知货物）验证对不同形状与重心位置的适应性。

**重点分析**：这篇解决的是"**连接点选在哪**"的问题，而不是控制器本身。对你们的意义：模块绑缚位置不是随便定的，它直接影响可控性；而重心估计可以借助测力计（各绑缚点力反推重心）实现，比贝叶斯成对估计更直接。

**可参考点**：
- 起飞前用测力计读数估计货物重心与惯量，据此选绑缚构型。
- 把"连接位置"作为优化变量，纳入构型选择。

## 2.4 模块化多旋翼结构的协同货运控制（2022）

**链接**：https://arxiv.org/abs/2210.04571

**做了什么**：研究通过模块化连杆网格机械耦合的多旋翼集群，建模结构弹性，控制器对柔性耦合鲁棒，并带自适应以处理非对称构型与未知负载；提出推力分配优化指标以最大化飞行时间，实验验证典型飞行、增大杆弹性与负载运输。

**重点分析**：它把"模块之间的连接杆"当成弹性结构建模，而不是理想刚体。你们的绑缚结构如果不够刚（货物柔性、绑带松弛），这篇的弹性建模与鲁棒控制就是参考。推力分配最大化飞行时间，等价于在推力约束下最小化能耗，可作为分配器的目标函数。

**可参考点**：
- 连接刚度不足时，把柔性纳入模型，不要假设纯刚体。
- 分配目标可设为"最小能耗/最大续航"，而非简单伪逆。

## 2.5 桌面力学启发的自组织空中集群载运（2025）

**链接**：https://arxiv.org/abs/2509.03563

**做了什么**：模仿桌子四条腿的耗散力学，提出去中心化耗散力模型，使飞行机器人集群在**不需要显式通信**的情况下实现编队稳定与自适应负载分配；稳定性有证明；仿真中在能力差异、缆绳不确定性、有限视觉、负载变化下跟踪误差分别为对比方法的 20%、68%、55.5%、21.9%；6 台机器人实验在单机失效、断连、25% 负载变化、40% 缆绳长度不确定性下达到 94% 成功率，并在 4 级风下飞行。

**重点分析**：这篇的核心主张是"**用局部力学反馈替代通信**"：每个机器人只根据邻居和负载的局部观测调整位置，就能实现负载分摊。对 ESP-NOW 链路受限的系统，这是最值得借鉴的思想之一。注意它的对象是缆绳悬挂，不是刚性绑缚；但"局部力/位置反馈 → 自适应负载分配"的逻辑可以迁移到测力计场景。

**可参考点**：
- 设计"力/位置反馈 → 负载份额"的局部规则，降低对高频通信的依赖。
- 断连与单机失效的实验设计值得照抄。
- 稳定性证明依赖耗散性，迁移到刚性连接需重新推导。

## 2.6 GPAC：无中心协调的几何控制与自适应质量估计（2026，IROS）

**链接**：https://arxiv.org/abs/2607.00024

**做了什么**：提出四层分层架构 GPAC，让 N 架四旋翼在**没有中心协调者、不交换缆绳状态/自适应参数**的情况下运输缆绳悬挂负载。核心是"隐式协调"：每架四旋翼从本地缆绳测量独立估计自己的有效载荷份额，合力自然收敛到正确总量，无需知道 N 或负载质量；负载位置由本地缆绳几何重建；唯一的机间通信是低频邻居位置广播（用于避撞）。系统还包含几何位置/姿态控制、抑摆、扩张状态观测器抗风、并发学习质量估计、CBF 安全滤波。作者报告仿真负载跟踪 RMSE 33.8 cm（13 个随机种子变异系数 2.8%）。

**重点分析**：这是"**测力计 + 分布式控制**"最直接的模板：每个模块只需要本地力测量就能知道自己该出多少力，通信只用于安全。你们的测力计正好提供这个"本地力测量"。把缆绳张力换成绑缚点力，逻辑高度相似。需要注意的是它假设缆绳是主要传力路径，刚性绑缚下内力分配更复杂，需要引入柔度或力控。

**可参考点**：
- 用测力计做"载荷份额估计"，把负载分配变成局部问题。
- 通信只保留低频邻居状态 + 避撞，控制回路不依赖它。
- CBF 安全滤波可作为力饱和/姿态可行域的保护层。

## 2.7 CrazyMARL：缆绳悬挂负载的去中心化 RL 控制（2025，ICRA 2026）

**链接**：https://arxiv.org/abs/2509.14126

**做了什么**：用去中心化强化学习直接输出电机控制，处理多无人机缆绳悬挂负载运输，重点解决缆绳"松弛-张紧"模式切换（此前工作多假设刚性连接）；作者报告在扰动抑制与跟踪精度上优于经典去中心化控制器，恶劣条件下恢复率 80% vs 基线 44%，并实现零样本 sim-to-real。

**重点分析**：它的价值不是"RL 比控制好"，而是展示了**接触/缆绳模式切换**这类难以用解析模型处理的情形，学习策略可以作为解析控制器的补充。对你的刚性绑缚系统，如果绑带松弛、货物晃动导致模型不确定，可以考虑"几何控制器 + 学习残差"的混合结构，而不是纯 RL。

**可参考点**：
- 把松弛-张紧视为混合动力学，单独处理模式切换。
- 学习策略用于补偿未建模动力学，保留几何控制器的稳定性保证。

## 2.8 多无人机运输系统的布局与控制协同设计（2023，RA-L 2025）

**链接**：https://arxiv.org/abs/2310.07649

**做了什么**：把多无人机协同运输系统看成"带推力模块的整机"，联合优化推力模块（无人机）在负载上的布局与控制器，使系统抗扰动能力最强；提出受 H2 控制启发的鲁棒性指标，并用 3–4 架四旋翼、多种形状负载做实验验证。

**重点分析**：构型（模块放哪）与控制（怎么分力）是耦合的，这篇给了联合优化的范式。对你们，模块布局/绑缚点选择可以直接套用这个"鲁棒性指标 + 布局优化"框架，尤其当货物形状会变时。

**可参考点**：
- 先定义鲁棒性指标，再做布局搜索，最后调控制器。
- 布局优化的结果可以固化成"货物形状 → 推荐绑缚方案"的规则。

## 2.9 空中机器人协同操作与运输（2009，RSS）

**链接**：https://doi.org/10.15607/RSS.2009.V.001

**做了什么**：Michael、Fink、Kumar 的经典工作：多架空中机器人协同抓取与运输物体，给出抓取矩阵、力分配与协同控制的框架，是"空中协同操作"的奠基论文之一。

**重点分析**：它把地面协同操作里的**抓取矩阵/力分配**引入空中机器人：给定期望合力与合力矩，如何分配到各机器人，同时满足摩擦/推力约束。你们的多模块绑缚本质上是同一类问题，只是"抓取"变成"绑缚"，力约束变成单旋翼推力与倾转约束。读它的价值是建立"内力 vs 外力"的概念：刚性连接会产生内力，分配器必须显式处理，否则模块间会"打架"。

**可参考点**：
- 用抓取矩阵形式描述"模块力 → 整机力旋量"的映射。
- 显式区分内力（不产生整机运动，但影响结构与能耗）与外力。
- 力分配加约束优化，而不是伪逆。

## 本章综合

| 问题 | 可借鉴方法 | 代表 |
| --- | --- | --- |
| 未知负载/质量 | SPR 化反馈、自适应估计 | 2.1、2.2、2.9 |
| 载荷在模块间怎么分 | 局部力测量 → 份额估计、耗散力学 | 2.5、2.6 |
| 绑缚点/构型选择 | 重心估计 + 可控性优化、布局-控制协同设计 | 2.3、2.8 |
| 柔性/松弛耦合 | 弹性建模、混合动力学、学习补偿 | 2.4、2.7 |
| 通信受限 | 隐式协调、低频广播 | 2.5、2.6 |

**与你的系统映射**：

1. **测力计 → 载荷份额估计**：GPAC 用缆绳张力、桌面力学用局部力反馈，你用的是绑缚点力，物理量一致。先把"每个模块应承担多少力"做成局部估计，再谈通信。
2. **ESP-NOW → 低频广播 + 事件触发**：2.5/2.6 都表明高频通信不是必需；把 ESP-NOW 用于慢速状态同步、构型/模式切换、避撞，控制回路本地闭环。
3. **单旋翼倾转 → 分配约束更硬**：单旋翼不能像四旋翼那样任意产生力矩，分配必须考虑倾转角与推力饱和（见 07）。
4. **刚性绑缚 → 内力问题**：2.9 的抓取矩阵框架提醒你，分配器要显式处理内力，否则模块间相互挤压、能耗上升。

**边界**：2.5/2.6/2.7 的对象是缆绳悬挂，不是刚性绑缚；它们的"隐式协调"依赖缆绳力的可测性。刚性绑缚的力测量更直接，但内力分配与结构柔度问题更突出，迁移时需要重新建模。
