# 03 协同搬运与载荷分配

> RQ2：多机搬运时载荷与力如何在成员间分配？刚性耦合与柔性耦合的差别是什么？未知负载如何处理？

## 3.1 问题定义

协同搬运可形式化为：给定期望整机运动（或期望货物轨迹），求各成员的推力/力指令，使

- 整机力旋量满足期望（合力 = 质量 × 加速度等）；
- 各成员不超过执行器约束；
- 连接处内力可控（刚性连接下内力不为零，会影响结构与能耗）；
- 对未知负载质量/惯量/质心具有适应性。

耦合方式决定难度：刚性连接需要显式处理内力；缆绳悬挂的内力由张力自然体现，但存在松弛-张紧切换。

## 3.2 方法族与代表工作

- **抓取矩阵/力分配**：Michael 等 [9] 把地面协同操作的抓取矩阵引入空中机器人，给定期望合力/合力矩后分配到各机器人，显式区分外力与内力。这是所有后续力分配的参照框架。
- **单旋翼刚性连接**：Oishi 等 [10] 用刚性连接的单旋翼机器人搬运未知负载，反馈控制器把系统 SPR 化，再叠加非线性跟踪；[11] 进一步证明对质量/质心波动与机器人失效的鲁棒性，仿真 8/10 台、实验 3 台异构机器人搬运约 3 kg、1.6 m 货物；[12] 用可变连接机构与贝叶斯重心估计选择连接位置，实验 8 台、约 3.2 kg、1.76 m。
- **柔性结构**：Modular Multi-Copter [13] 把模块间连杆建成弹性结构，控制器对柔性耦合鲁棒，推力分配以最大化飞行时间为目标。
- **隐式协调**：GPAC [14] 让每架四旋翼从本地缆绳测量估计自身载荷份额，无需中心协调、无需交换缆绳状态，唯一机间通信是低频邻居位置广播；Table-Mechanics [15] 用耗散力学让集群在无显式通信下完成编队稳定与负载分配，6 机实验在单机失效/断连/25% 负载变化下达到作者报告的 94% 成功率。
- **学习策略**：CrazyMARL [16] 用去中心化 RL 直接输出电机指令，处理缆绳松弛-张紧切换，作者报告零样本 sim-to-real。
- **布局-控制协同设计**：Layout Co-Design [17] 联合优化推力模块在负载上的布局与控制器，用 H2 风格指标评估抗扰性，3–4 机实验验证。

## 3.4 证据强度与局限

- A 级证据集中在单旋翼刚性连接（[10][12]）与早期抓取矩阵（[9]）；隐式协调与学习路线均为 B 级预印本，数字未经独立复现。
- 刚性连接的实验规模普遍在 3–8 个模块，货物 2.7–3.2 kg；没有工作同时做到"刚性绑缚 + 单旋翼 + 测力计 + 低带宽通信"。
- 缆绳工作 [14][15] 的"无/低通信"结论依赖张力可测；刚性绑缚下力传感器测量的是绑缚点合力（含内力），不能直接等同张力。

## 3.5 对目标系统的启示（推断）

1. **测力计的定位是"隐式协调 + 内力监测"**：用绑缚点力估计载荷份额（对齐 [14][15]），同时用力的不一致检测内力/装配异常（文献中较少见）。
2. **单旋翼刚性连接已有可复现基线**：[10][11][12] 的控制器结构与实验规模可直接作为对照。
3. **不要直接照搬缆绳结论**：刚性连接下内力不可忽略，分配器要显式建模（[9] 的抓取矩阵形式仍适用）。
4. **布局优化应前置**：绑缚点选择影响可控性与能耗（[12][17]），应在设计阶段做，而不是靠控制器补偿。

**本章结论**：协同搬运的方法谱已覆盖刚性/柔性、显式/隐式、模型/学习；空白在于"刚性绑缚 + 可测内力 + 单旋翼执行器约束"这一组合（10 章 G2、G3）。
