# 01 模块化与可重构飞行器

> 本章回答三个问题：模块怎么拼成一架能飞的飞机；拼出来的构型怎么被控制器当成"一个对象"；构型变化、对接与分离的过渡过程怎么保证可控。

你的系统是把多个单旋翼倾转模块绑成一体，本质上是 **Modular Aerial Robot Systems（MARS）** 的一个实例。这一章的价值不在算法细节，而在"模块化无人机的系统分层"——哪些问题必须在架构层解决，哪些可以留给控制层。

## 两条路线与三个共性问题

- **同构可重构**：模块规格相同，靠增减数量和排列改变推力与自由度（MARS、H-ModQuad）。适合你的多模块绑缚场景。
- **通用附着**：模块贴到任意刚性物体上，物体本身成为机身（UFO）。适合"货物形状不固定"的变体。
- **共性问题**：① 构型变化后，控制器如何复用；② 模块推力/力矩的可行集合如何描述与分配；③ 对接、分离、重构的中间态如何保持稳定。

## 1.1 MARS-Dragonfly（2026）

**链接**：https://arxiv.org/abs/2604.05499

**做了什么**：针对 MARS 现有控制依赖准静态模型和规则分配、模块数增加后姿态误差累积的问题，作者做了三件事：设计被动对接、免检测被动锁止、磁辅助分离的紧凑机械结构（单个微型舵机驱动）；提出"力-力矩等效 + 多面体约束的虚拟四旋翼"抽象，显式建模可行力旋量集合，使现成四旋翼控制器能跨构型复用；再用两阶段预测分配（先算满足力/力矩边界的虚拟输入，再动态分配到各模块）产生平滑、可跟踪的电机指令。作者报告在 10 种以上构型仿真与实机实验中实现 40° 峰值俯仰、平均位置误差 0.0896 m。

**重点分析**：这篇最值得抄的是**分层方式**。它没有为每种构型写一个控制器，而是把构型差异吸收到两个地方：虚拟四旋翼的力旋量多面体（描述"这个构型能产生什么"），以及分配器（描述"怎么分给模块"）。这样构型从"控制问题"降级为"参数问题"。对单旋翼倾转模块，这个抽象同样成立，但可行力旋量集合与四旋翼模块不同：单模块推力方向随倾转角变化，多面体需要按倾转角和饱和重建。

**可参考点**：
- 先定义"整机虚拟控制输入"与"可行力旋量多面体"，再接你们自己的分配算法。
- 构型切换时只重建多面体与分配矩阵，不换控制器。
- 对接/分离阶段单独给控制模式，不要把过渡态塞进巡航控制器。

## 1.2 MARS-FTCP（2025）

**链接**：https://arxiv.org/abs/2503.09351

**做了什么**：提出适配任意模块数与装配构型的容错控制重分配方法：按各模块相对整机质心的力臂重新分配期望合力/合力矩；同时给出适用于任意构型的敏捷轨迹规划（避撞、动态可行）。作者称这是首个同时覆盖 MARS 容错与避撞飞行的工作，并开源了代码（github.com/RuiHuangNUS/MARS-FTCP）。

**重点分析**：按力臂分配是 MARS 类系统的自然选择，但它的隐含前提是"每个模块的推力上限相同、方向可控"。单旋翼倾转模块的力臂与推力方向都随构型变化，分配矩阵需要在线更新。另一个可借鉴点是**把轨迹规划与当前构型绑定**：构型变了，可行加速度包络也变，轨迹不能沿用。

**可参考点**：
- 分配权重取"力臂 × 可用推力"，故障模块权重置零并重新归一。
- 轨迹规划传入当前构型的加速度/角加速度约束，而不是固定参数。
- 开源实现可直接对照分配公式的数值稳定性处理。

## 1.3 TransforMARS（2025，ICRA 2026）

**链接**：https://arxiv.org/abs/2509.14025

**做了什么**：把容错重构推广到任意形状 MARS 与多重转子/模块故障：先识别并构造包含故障模块的"最小可控装配体"，再规划可行的拆-装序列，把模块或子装配体搬运到目标构型，并保证空中连续稳定。作者报告在任意形状构型上，可处理的构型种类与可容忍故障数均显著超过只针对矩形 MARS 单故障的前作。

**重点分析**：这篇把重构从"换个形状"提升为**带约束的规划问题**：每个中间装配体都必须可控，序列必须物理可行。对你的系统，如果要做"坏一个模块就拆掉重排"，这就是现成的框架。难点在于最小可控装配体的判定依赖你的单旋翼模块的力旋量能力，不能照搬四旋翼的判据。

**可参考点**：
- 把"重构"建模成状态机 + 序列规划，每一步校验可控性。
- 先定义最小可控单元（几个模块、什么排布）作为规划基元。

## 1.4 Robust Self-Reconfiguration（2025）

**链接**：https://arxiv.org/abs/2503.09376

**做了什么**：指出现有 MARS 重构工作忽略重构过程中**中间结构**的可控性，提出在控制受限动力学模型下，最大化每个中间阶段的可控性裕度，并计算最优拆装序列，减少装配步数。

**重点分析**：与上一篇互补：TransforMARS 关注"能不能重构成"，这一篇关注"重构途中稳不稳"。对绑缚货物的系统，拆装途中货物可能只由部分模块支撑，中间态的推力裕度和力分配比最终构型更危险。

**可参考点**：
- 重构规划的目标函数加入"中间态可控性裕度"，而不只是终点构型。
- 用可控性裕度做重构的安全门限，低于门限就拒绝该步。

## 1.5 Universal Flying Objects（2019）

**链接**：https://arxiv.org/abs/1911.03615

**做了什么**：提出 UFO：把刚性物体变成多旋翼的模块化平台，由控制模块与推进模块组成，贴到物体上，物体本身成为机身。用 IMU 估计模块相对构型，配合自适应几何控制器在线修正未知参数；用 4–8 个推进模块托举约 200–800 g 的哑负载，实现悬停与轨迹跟踪，作者报告参数收敛后位置误差为厘米级。

**重点分析**：这是"模块 + 任意货物"路线的代表。它的核心贡献是**构型自辨识**：不需要事先知道模块装在哪，IMU 数据加自适应控制就能收敛。对你的系统，如果模块与货物的相对位置会变（换货物、换绑法），这套"在线辨识 + 自适应"比手工标定更现实。

**可参考点**：
- 用每个模块的 IMU + 整机运动估计相对构型，减少对精确装配的依赖。
- 自适应参数（质量、惯量、安装位置）在线估计，控制器只需近似值。

## 1.6 LEGION：自组装模块化飞行器（2026）

**链接**：https://arxiv.org/abs/2605.19431

**做了什么**：提出可空中自组装的模块化飞行机器人 LEGION：每个单元两端带关节式对接接口，多单元自主对接后通过控制接触力/力矩维持零间隙互锁，形成可articulated运动的飞行机械臂；演示了推、拉、旋转、抓取、搬运等空中操作原语，并在户外验证。作者将其定位为"从被动观察者到主动参与者"的空中物理交互平台。

**重点分析**：它讨论的是**对接瞬间的力控制**，而不是位姿对齐就完事。零间隙互锁要求接触力受控，否则对接会弹开或卡死。你的模块通过 ESP-NOW + UWB 协同，对接/绑缚阶段同样需要力控与状态机配合；这篇提供了"对接接口 + 接触力控制 + 形态切换"的完整例子。

**可参考点**：
- 对接/绑缚阶段用测力计做接触力闭环，而不是只靠位置误差。
- 把"个体飞行"和"组合体飞行"做成两种控制模式，切换有明确条件。

## 1.7 Modular Multi-Rotors / H-ModQuad（2022）

**链接**：https://arxiv.org/abs/2202.00788

**做了什么**：提出由倾斜旋翼驱动的长方体模块 H-ModQuad，通过组合模块把可控自由度从 4 扩展到 5、6，提高载荷能力；用驱动椭球与力旋量多面体刻画不同构型的驱动能力，找推力效率最高的机体坐标系；给出动力学与控制，并用实机验证不同构型的驱动特性。

**重点分析**：这是"模块设计空间"的定量分析：构型不只是数量，还包括旋翼倾角与安装几何。对单旋翼倾转模块，倾转角本身就是设计变量，这篇的椭球/多面体方法可以直接用来比较"倾转多少度、模块间距多大"更利于搬运。

**可参考点**：
- 用驱动椭球比较候选构型，而不是试飞。
- 把"可控自由度"作为构型选择的硬指标。

## 1.8 Modular Self-Reconfigurable Robot Systems（2007）

**链接**：https://doi.org/10.1109/MRA.2007.339623

**做了什么**：模块自重构机器人领域的奠基性综述（Yim、Shen 等），系统梳理模块化机器人的体系结构、自主重构（metamorphosis）、对接机制、控制与规划挑战，提出该领域的"grand challenges"。

**重点分析**：虽然对象是地面/通用模块机器人，但它给出的分层（模块、连接、构型、规划、自主性）至今适用。读它的价值是建立术语与问题地图，避免把"模块化"只理解成机械拼接。

**可参考点**：
- 用它的自主性分级评估你们系统当前处在哪一级（遥控 / 预设构型 / 自主重构）。
- 对接机制的分类可直接用于选型。

## 本章综合

| 设计问题 | 可借鉴的做法 | 代表工作 |
| --- | --- | --- |
| 构型变化后控制器复用 | 虚拟刚体 + 可行力旋量多面体 + 分配层 | 1.1、1.7 |
| 构型未知/装配误差 | IMU 构型自辨识 + 自适应控制 | 1.5 |
| 重构过程安全 | 中间态可控性裕度 + 拆装序列规划 | 1.3、1.4 |
| 对接/分离 | 接触力闭环 + 控制模式切换 | 1.1、1.6 |
| 模块化程度的评估 | 自主性分级与对接机制分类 | 1.8 |

**边界**：以上工作绝大多数以四旋翼为模块。单旋翼倾转模块的推力方向随倾转角变化，可行力旋量集合不是常值多面体，需要按倾转角重建；这一点在后续章节（07 控制分配）展开。直接照搬四旋翼的分配矩阵会在倾转饱和时出错，这是本仓库要特别提醒的坑。
