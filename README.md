# 模块化无人机协同搬运：一篇面向系统落地的综述

本仓库是一篇**综述**，而不是论文合集。它研究的问题是：由多个单旋翼倾转模块绑缚成一体、协同搬运货物的飞行器，在模块间通信带宽低、无硬件时间同步、执行器方向受限的条件下，如何完成相对定位、载荷分配与分布式协同，并在模块故障或构型变化时保持可控。

综述的落点不是"读过哪些论文"，而是：**这个领域的方法谱长什么样、证据强到什么程度、哪些格子是空的、哪个创新点值得先做。**

## 综述贡献

1. **检索与证据方法**（[00](docs/00_survey_method.md)）：48 组 arXiv 检索式 + Crossref 补充检索，明确纳入/排除标准与 A/B/C 证据分级，可复现。
2. **七维分类学**（[01](docs/01_taxonomy.md)）：模块形态、机械耦合、信息结构、控制方法族、定位与同步、故障处理、评测方式；39 篇工作在同一坐标系中定位，并给出覆盖矩阵。
3. **方法族横向对比**（[02](docs/02_modularity.md)–[09](docs/09_evaluation.md)）：每章按"问题定义 → 方法族 → 对比表 → 证据强度 → 对目标系统的启示"组织，而不是逐篇摘要。
4. **Gap 分析**（[10](docs/10_gaps.md)）：8 条 gap 全部从覆盖矩阵与对比表空缺推出，标注证据与可做性。
5. **创新点候选评分**（[11](docs/11_innovation_scoring.md)）：5 个候选、公开权重、逐条打分依据、敏感性分析、论文导向落地矩阵；**主线由项目方选定**。

## 目标系统画像

单旋翼倾转模块（每模块自带飞控、UWB、测力计、ESP32-S3 XIAO），ESP-NOW 模块间通信，UWB 测距，测力计测绑缚点力，多模块绑缚货物协同飞行。这套画像决定综述的筛选偏好：**力是否可测、通信是否受限、执行器方向是否受限**。

## 主要发现（结论先行）

1. **力感知是降低通信依赖的关键**：缆绳悬挂工作在无/低通信下实现载荷分配（[14][15]），刚性绑缚的抓取矩阵框架显式处理内力（[9]）；但两者都没有覆盖"刚性绑缚 + 可测内力 + 单旋翼"的组合（G2）。
2. **单旋翼模块协同搬运已有直接先例**：Oishi 系列用刚性连接的单旋翼机器人搬运未知负载并演示失效下继续飞行（[10][11][12]），可作为基线。
3. **模块化飞行器的成熟做法是"抽象 + 分配 + 规划"三层**（[2][4][6][7]），但对象几乎都是四旋翼模块；单旋翼倾转模块的可行力旋量与重构判据仍是空白（G1）。
4. **通信要按网络化控制系统设计**：采样/时延/丢包/数据年龄与控制器联合定；广播冗余与编码优于逐包重传（[18][20][21]）。
5. **评测缺统一协议**：通信条件、故障注入、基线三件事不同时报告，数字不可比（G7）。

## 证据与可信度

- 检索与核对日期：**2026-10-19**；39 篇论文（33 arXiv + 6 DOI）。
- 链接全部实测可达（arXiv HTTP 200，DOI 302 跳转出版社）；标题与 arXiv API / Crossref 元数据逐字比对。
- 论文数字一律标"作者报告"，未复现；"推断/待验证"为我们的分析，与论文结论分开。
- 证据分级：A 同行评议、B 预印本、C 综述/分类；详见 [00](docs/00_survey_method.md)。

## 局限

只覆盖 arXiv/Crossref 可检出的英文文献；2025–2026 工作多为预印本；不复现；以单旋翼倾转模块为参照，四旋翼/缆绳工作仅作对照。ESP-NOW 无对应学术文献，相关讨论为工程注记。
