# 模块化无人机协同搬运：一篇面向系统落地的综述

本仓库是一篇**综述**，而不是论文合集。它研究的问题是：由多个单旋翼倾转模块绑缚成一体、协同搬运货物的飞行器，在模块间通信带宽低、无硬件时间同步、执行器方向受限的条件下，如何完成相对定位、载荷分配与分布式协同，并在模块故障或构型变化时保持可控。

综述的落点不是"读过哪些论文"，而是：**这个领域的方法谱长什么样、证据强到什么程度、哪些格子是空的、哪个创新点值得先做。**

3. **方法族横向对比**（[02](docs/02_modularity.md)–[09](docs/09_evaluation.md)）：每章按"问题定义 → 方法族 → 对比表 → 证据强度 → 对目标系统的启示"组织，而不是逐篇摘要。
4. **Gap 分析**（[10](docs/10_gaps.md)）：8 条 gap 全部从覆盖矩阵与对比表空缺推出，标注证据与可做性。
5. **创新点候选评分**（[11](docs/11_innovation_scoring.md)）：5 个候选、公开权重、逐条打分依据、敏感性分析、论文导向落地矩阵；**主线由项目方选定**。
6. **跨学科候选池**（[12](docs/12_cross_disciplinary.md)）：12 个领域外透镜（无源性/ADMM/CRDT/弹性共识/网络科学/结构健康监测/柔性连接/合作博弈/预测编码/振荡器同步/模块化设计理论/编队气动），每个给出可检验实验与评级。
7. **知识体系与多学科整合**（[13](docs/13_knowledge_system.md)）：五层知识栈、概念依赖图、多学科整合矩阵、15 个关键知识节点、研究能力四级地图，以及三轮滚动检索的完整记录与知识更新机制。
8. **可行性预算与判别实验**（[14](docs/14_feasibility_budget.md)）：ESP-NOW 带宽、传感链上限、内力可测性的量化预算，三个两周内可完成的地面判别实验（D1–D3），以及 A/B 主线的决策规则——把"选哪条线"从偏好变成判据。
9. **判别实验协议**（[15](docs/15_experiment_protocols.md)）：D1–D3 的设备清单、标定步骤、测试矩阵、预注册判据、数据格式与只依赖标准库的分析脚本；含 CUSUM 误报-延迟预研（h=8 时 ARL₀≈1.9×10⁴，20 Hz 下 10 min 误报约 0.6 次）。
10. **力残差检测数值预研**（[16](docs/16_force_residual_sim.md)）：单模块故障下"四路平均"是负收益（SNR 砍半），正确形态是并行 CUSUM + OR + 力台仲裁；脚本与 JSON 可复现（种子 20261019）。
11. **主线公共部分**（[17](docs/17_mainline_common.md)）：A/B 两条候选共享的问题定义（RQ0 + C1–C4）、平台参数单一事实源（P1–P11）、系统模型（τ=Gf、6 维零空间、可行力集合）、分层架构与接口、指标/基线、论文骨架与主张-证据审计；A/B 分叉只留三处，等 D1–D3 出数后填。
12. **数据年龄与协同环频率的排队模型**（[18](docs/18_data_age_sim.md)）：把"数据年龄"拆成交付年龄与陈旧度，给出 10/20/50/100 Hz 下的交付/陈旧 P95、占空，以及事件触发的心跳约束；100 Hz 在 250 kbps 下排队发散。脚本 `experiments/espnow_age_sim.py` 固定种子复现全部数字。
13. **检测预算的物理时间账**（[19](docs/19_detection_budget.md)）：20 Hz 检测只过中位（P95 158 ms），25–26.7 Hz 才能全过；σ=3% 需原始 80 SPS（P95 138 ms）；50/80 Hz 的 h 要抬到 8.6/9.0 才守住误报。脚本 `experiments/d2_detection_budget_sim.py` 复现。
14. **内力可测性的工程前提**（[20](docs/20_internal_force_identifiability.md)）：载荷份额与内力代数上可分离（`G` 秩 6、零空间 6 维），但实测内力被装夹预紧（聚合 10–101 N）与热漂移（10 K 下 13.8 N）主导，是 10% 推力信号（0.49 N）的 20–200 倍；D3 的 `CV<10%` 实为装夹重复性判据。脚本 `experiments/internal_force_identifiability_sim.py` 复现。
15. **数据回填手册**（[21](docs/21_backfill_playbook.md)）：把 14–20 章的"假设/待实测"逐条落到 `runs/` 字段与回填表，给出 7 步回填顺序、决策表数据依赖、当前状态看板，以及校验脚本 `experiments/validate_runs.py`（缺字段即非零退出）。
16. **投稿骨架与主张审计**（[22](docs/22_submission_skeleton.md)）：15 条可投稿主张逐条钉到源章节与数字，含中英摘要草稿、章节骨架、图表清单、venue 选择与 6 条审稿风险；`experiments/paper_claims.json` + `experiments/check_claims.py` 强制骨架与正文数字不分叉（不一致即非零退出）。
17. **相关工作对照表**（[23](docs/23_related_work_table.md)）：43 篇最接近工作按"平台与耦合/通信假设/力感知/故障/与本文差异"六列重排成主稿 Table 1，给出三条增量与覆盖声明；`experiments/check_related_table.py` 校验引用编号与表结构（越界或列数不足即非零退出）。
18. **引言与相关工作的文字稿**（[24](docs/24_intro_related_prose.md)）：按 RA-L 写法给出 Introduction 五段（场景→两个问题→已有工作缺什么→三条贡献→组织）与 Related work 四族文字版，全部数字带主张编号 C1–C15；`experiments/check_intro.py` 校验"不漏引主张、不引不存在的编号"（任一不满足即非零退出）。
19. **投稿材料包**（[25](docs/25_submission_package.md)）：cover letter、5 条 ≤85 字符的 Highlights、作者贡献/利益冲突/数据可用性/资助声明模板、审稿人 6 问预备回答、一条命令一项的投稿检查清单；`experiments/check_submission.py` 校验 Highlights 字数、主张编号、占位符与内链（任一不满足即非零退出）。

## 目标系统画像

单旋翼倾转模块（每模块自带飞控、UWB、测力计、ESP32-S3 XIAO），ESP-NOW 模块间通信，UWB 测距，测力计测绑缚点力，多模块绑缚货物协同飞行。这套画像决定综述的筛选偏好：**力是否可测、通信是否受限、执行器方向是否受限**。

## 主要发现（结论先行）

1. **力感知是降低通信依赖的关键**：缆绳悬挂工作在无/低通信下实现载荷分配（[14][15]），刚性绑缚的抓取矩阵框架显式处理内力（[9]）；但两者都没有覆盖"刚性绑缚 + 可测内力 + 单旋翼"的组合（G2）。
2. **单旋翼模块协同搬运已有直接先例**：Oishi 系列用刚性连接的单旋翼机器人搬运未知负载并演示失效下继续飞行（[10][11][12]），可作为基线。
3. **模块化飞行器的成熟做法是"抽象 + 分配 + 规划"三层**（[2][4][6][7]），但对象几乎都是四旋翼模块；单旋翼倾转模块的可行力旋量与重构判据仍是空白（G1）。
4. **通信要按网络化控制系统设计**：采样/时延/丢包/数据年龄与控制器联合定；广播冗余与编码优于逐包重传（[18][20][21]）。
5. **评测缺统一协议**：通信条件、故障注入、基线三件事不同时报告，数字不可比（G7）。
6. **协同环的现实上限是 20–25 Hz**：ESP-NOW 全广播 20 Hz 占空约 30.7%，全单播 20 Hz 已 92.2%；100 Hz 协同需 384 kbps，超出链路能力。低通信不是妥协，是这套硬件唯一可行区间（[14](docs/14_feasibility_budget.md)）。
7. **数据年龄要拆成两个量**：20 Hz 交付 P95 ≈ 8 ms，但陈旧度 P95 ≈ 72 ms（约 1.4 个周期）；100 Hz 在 250 kbps 下排队发散（10 min 积压约 322 s）。控制器时延裕度按 35 ms 留会低估一倍，按 1.5T 留（[18](docs/18_data_age_sim.md)）。
8. **150 ms 检测预算要按检测节拍算，不是通信节拍**：20 Hz 检测 P95 约 158 ms（超 8 ms），26.7 Hz 降到 122 ms；σ=3% 时连 26.7 Hz 都不够，改用原始 80 SPS 反而降到 138 ms。降采样平均是检测的负收益（[19](docs/19_detection_budget.md)）。
9. **"内力可测"不等于"内力可分离"**：12 路测点里约 69% 的分量天然落在零空间；但装夹预紧（0–1 mm 误差、刚度 10⁴–10⁵ N/m → 10–101 N）与热漂移（10 K → 13.8 N）比 10% 故障信号大 1–2 个数量级。A 主线只能主张"相对基线的残差检测"，且必须记录温度与装夹预紧（[20](docs/20_internal_force_identifiability.md)）。

## 证据与可信度

- 检索与核对日期：**2026-10-19**；78 篇核心论文（第一轮 39 = 33 arXiv + 6 DOI；第二轮补充 30；第三轮复核新增 6；第四轮定向补查新增 3；后两轮全部 arXiv）+ 8 篇跨学科锚点（DOI/HAL，见 [12](docs/12_cross_disciplinary.md)）。
- 多轮滚动检索：第二轮（30 篇）做引文反查 + 2025–2026 时间窗扫描 + 窄短语；第三轮（6 篇）用 10 组边界族检索式复核遗漏。三轮记录见 [13.6](docs/13_knowledge_system.md)；每篇均经 arXiv `id_list` 逐条核对标题与首次提交日期。
- 链接全部实测可达（arXiv HTTP 200，DOI 302 跳转出版社，HAL 200）；标题与 arXiv API / Crossref 元数据逐字比对。
- 论文数字一律标"作者报告"，未复现；"推断/待验证"为我们的分析，与论文结论分开。
- 证据分级：A 同行评议、B 预印本、C 综述/分类；详见 [00](docs/00_survey_method.md)。

## 局限

只覆盖 arXiv/Crossref 可检出的英文文献；2025–2026 工作多为预印本；不复现；以单旋翼倾转模块为参照，四旋翼/缆绳工作仅作对照。ESP-NOW 无对应学术文献，相关讨论为工程注记。
